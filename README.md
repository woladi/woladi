# Adrian Wołczuk

Software developer building native macOS tools and AI-powered CLI utilities.

## Projects

### [macos-vision](https://github.com/woladi/macos-vision)
Apple Vision OCR & image analysis for Node.js — native, fast, offline, no API keys required. Wraps macOS's built-in Vision framework via a compiled Swift binary.

```bash
npm install macos-vision
```

### AiSort
AI-powered document sorter using Apple Vision and Ollama. Automatically classifies and organizes files using local LLMs — no cloud, no subscriptions.

## Tech

TypeScript · Node.js · Swift · Apple Vision · Ollama · macOS native APIs
